# FE 연동 현황

기준 문서는 백엔드 레포의 `docs/API.md` (계약 v0.3, 지섭님 `feat/stage3-inbox-records-cancel`)예요.
예전에 FE가 따로 요청했던 계약(색 단위 전송, 친구 여러 명 등)은 v0.3으로 대체됐어요.

## 반영한 것 (11/16)

- 가입: 아이디 소문자·숫자·밑줄 4~20자, 비밀번호 8자 이상, 아이디 중복 확인
- 보내기: 색 1~2개 → 색마다 단어 1개 → AI 음악(설명 선택, 3초마다 상태 확인, 실패한 곡만 다시) → 친구 1명 / 나에게 / 익명
- 보내기 취소: 받은 사람마다 따로 취소 (5분 + 안 열어본 사람만)
- 받은 구슬: 반응 3개(code 전송), 신고 사유 4개(기타만 내용), 익명 차단, 3곡 순서 재생(토큰 헤더), 재생 버튼
- 기록·수신함·친구 목록: cursor 끝까지 읽기, 기록은 최근 12주(from), 대표 색 동률 규칙, 받은 기록 삭제 막기
- 케어: 서버 notice 가 있을 때만 홈 카드, 누르면 VIEWED / 닫으면 DISMISSED
- 토큰: 만료 시각 저장, 음원 재생 직전 갱신

## 아직 안 한 것

- 푸시 기기 등록 (`PUT /me/devices/{id}`): expo-notifications 설치 + 재빌드 필요
- 연령 확인: 백엔드 API 없음 (새 계정은 익명 불가). 방식 결정 필요
- 실제 AI 음악: 운영 서버는 503. 공급자 결정 필요
